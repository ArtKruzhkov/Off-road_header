An adaptive and interactive header for an off-road vehicle selection website.  
The project demonstrates a modern UI with animations and extended functionality.

## ✨ Features

- 🔸 Custom animated cursor with hover effects  
- 🔸 Two synchronized sliders (text + images)  
- 🔸 Parallax effect for images (Swiper.js)  
- 🔸 Animated gear rotation on slide change (GSAP)  
- 🔸 Slide counter with smooth number transitions  
- 🔸 Custom pagination, scrollbar, and navigation  
- 🔸 Modal window for requests (Micromodal)  
- 🔸 Social media and sharing buttons built into the header  
- 🔸 Full responsiveness: desktop / tablet / mobile

## 🛠️ Tech Stack

- **HTML5 / SCSS** — markup and styling  
- **JavaScript (ES6+)** — interaction logic  
- **Swiper.js** — slider with parallax, pagination, and scrollbar  
- **GSAP** — animations (cursor, numbers, gear rotation)  
- **Micromodal.js** — lightweight modal window  
- **Gulp** — project build system
